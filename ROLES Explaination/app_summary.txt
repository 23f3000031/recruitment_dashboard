=== RECRUITPRO COMPLETE APPLICATION SUMMARY ===

OVERVIEW:
RecruitPro is a comprehensive Flask-based Recruitment Management System designed to streamline the entire hiring process from candidate application to onboarding. Built with Python, Flask, SQLAlchemy, and Bootstrap5, it provides a complete solution for recruitment teams of all sizes.

CORE ARCHITECTURE:
- Framework: Flask 3.1.0 with Flask-SQLAlchemy 3.1.1
- Database: SQLite with migration support
- Frontend: Bootstrap5 with custom styling
- Authentication: Flask-Login with role-based access control
- Templates: 20+ HTML templates with responsive design
- JavaScript: Interactive features (sidebar, dark mode, search)

ROLE-BASED ACCESS CONTROL:
Three distinct user roles with progressively restricted access:

1. ADMINISTRATOR (Full Access)
   - User management (add, edit, delete users)
   - System configuration (SMTP, preferences)
   - All features and modules available
   - Analytics and reports access
   - Job posting management
   - Complete dashboard analytics

2. RECRUITER (Limited Access)
   - Candidate management (CRUD operations)
   - VCT verification oversight
   - Interview scheduling and management
   - Assessment assignment
   - Document generation
   - Limited analytics view
   - Cannot manage users or system settings
   - Cannot delete candidates

3. INTERVIEWER (Focused Access)
   - Interview feedback submission
   - Interview viewing and details
   - Rating and recommendation submission
   - Access to scheduled interviews only
   - Limited dashboard view
   - Cannot manage candidates, assessments, or documents
